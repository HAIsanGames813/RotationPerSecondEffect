# 指定秒間回転

## インストール
[ここからダウンロード](https://github.com/HAIsanGames813/RotationPerSecondEffect/releases/latest)

## 概要
指定した秒数で何回回転するかを指定できる映像エフェクトを追加するプラグインです

## 使用方法
アニメーションタブから追加し「指定秒間回転」を追加し何秒間でどの軸を何回転するか設定することで使用できます
回転数を負の値にすると反時計回りになります  

※exo出力には対応してません
